MODELO PRODUTOS - PADRÃO SIMPLES DO PROFESSOR

1. Abra esta pasta (01_PRODUTOS) no VS Code.
2. Terminal > New Terminal. Confira que está na pasta com package.json.
3. Execute npm.cmd install (uma vez).
4. Execute node servidor.js.
5. Abra http://localhost.
6. Cadastre um registro; clique em Ver cadastrados para consultar com find().
7. MongoDB Compass: mongodb://localhost:27017 > prova_fullstack > produtos > Documents/Find.
8. Para parar: Ctrl+C no terminal.

ERROS COMUNS
- Cannot find module: rode npm.cmd install nesta pasta.
- npm não reconhecido: Node.js precisa estar instalado. Teste node -v.
- npm.ps1 bloqueado: use npm.cmd install.
- ECONNREFUSED 27017: MongoDB Server precisa estar em execução; Compass sozinho não inicia o banco.
- EADDRINUSE 80: já há servidor na porta 80; pare com Ctrl+C.
- Página não abre: confira o terminal e http://localhost.
- cd com espaços: use cd "nome da pasta".

ALTERAR NA PROVA
- public/style.css: cor do fundo, largura e centralização.
- views/home.ejs: título, nomes dos campos e formulário.
- servidor.js: campos recebidos em req.body, banco, coleção e rotas.
- views/lista.ejs: nomes dos campos exibidos.

IMPORTANTE: O professor colocou os nomes acima dos inputs, alinhados à esquerda.
Este modelo mantém isso, mas centraliza o formulário pequeno.

GUIA DOS COMENTARIOS: servidor.js explica conexao, rotas, POST, req.body, insertOne e find. home.ejs explica formulario e inputs. style.css explica fundo, tamanho e centralizacao.

DEPENDÊNCIAS: express@4.21.2, body-parser@1.20.3, ejs@3.1.10 e mongodb@4.12.0.
Já existe package.json: NÃO é necessário rodar npm init -y de novo.
A pasta node_modules não deve ser enviada ao GitHub.
Se aparecer 'Cannot find module': rode npm.cmd install nesta pasta.
Se aparecer 'Cannot GET /cadastrar': confira se o formulário usa method=POST e action=/cadastrar.
Se aparecer 'ECONNREFUSED 127.0.0.1:27017': verifique se o serviço MongoDB está ligado.
Se aparecer 'EADDRINUSE': outra aplicação está usando a porta 80; pare o servidor anterior com Ctrl+C.
Se 'npm' for bloqueado no PowerShell: use npm.cmd install.
Se 'node' não for reconhecido: confirme a instalação do Node.js com node -v.
Se a lista estiver vazia, cadastre um item e confira o banco e coleção no Compass.
ATENÇÃO: o Compass é um visualizador; o servidor MongoDB precisa estar em execução.
O teste de execução real depende do Node.js e MongoDB disponíveis na máquina.
